# Carry-Forward Ledger (facts measured in the Learn Java run)

- `clip-path` on a list clips its children's focus outlines: an inset outline on a layer lost both sides inside a trapezoid glass. Lift the clip with `:focus-within`, and use a two-tone ring on any fill.
- `filter: drop-shadow` on a parent applies to every child: a rim shadow meant for a clipped glass also blurred the caption under it. Put the filter on a wrapper around the clipped element alone; a filter on the clipped element is clipped too.
- A typeset step that marks long inline `<code>` as wrappable (`white-space: normal`) also caught `<code>` inside `<pre>` and collapsed a javap listing into one line. Give block code a class, so the rule cannot reach it.
- CSS `order` reorders the paint but not the Tab order. A hero laid out with `order` on phones made focus jump from y≈450 back to y≈93. Make the source order the phone reading order, and use grid areas for wider layouts.
- A 3 px `min-width` on proportional segments inflated the smallest by up to 6.25× (Tufte). Proportional bars take no floors; a divider goes inside a segment, not as a gap.
- A program's ribbon must sum every class file javac writes (nested classes, records, sealed members), or the strip leaves out what the lesson teaches.
- `javac --release N` in JDK 21 accepts 8 and up. Minimums below 8 cannot be proven by the build and must be marked as history.
- `a && b` fails in Windows PowerShell 5.1. Give commands as separate lines.
