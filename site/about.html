About this site

One Python script, _src/build.py, compiles every program in examples/, runs it, reads the class file it makes, and writes these pages from the results.

The last build

On 2026-11-11, with javac 21.0.12.1: 13 programs compiled with javac -Xlint:all, 0 warnings, and every one ran and exited 0. With --no-run, or without a JDK, the build reuses those stored results, and this date says when they were made.

Getting a JDK

A JDK (Java Development Kit) gives you javac to compile and java to run. You type both in a terminal (Terminal on macOS, a Linux shell, or Windows Terminal).

  • Any system: download a free JDK 21 or newer from Eclipse Temurin and run its installer.
  • macOS with Homebrew: brew install openjdk@21.
  • Debian or Ubuntu: sudo apt install openjdk-21-jdk (sudo asks for your password).
  • Windows: in PowerShell, winget install EclipseAdoptium.Temurin.21.JDK, then open a new window.

Check it with javac -version. Then download any program from its lesson. In the terminal, move to the folder it saved to with cd (for example cd Downloads), paste the command printed under the program, and compare what it prints with the dark output box.
