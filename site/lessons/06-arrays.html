Arrays

A fixed-length row of values, sorted, and checked at every index.

An array’s length is fixed when it is created and read with .length. The enhanced for loop visits each element. Unlike C, Java checks every index: reading past the end throws an ArrayIndexOutOfBoundsException instead of reading whatever memory follows. The program catches it to print the message; the exceptions lesson explains catching.
