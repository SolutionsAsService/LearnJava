Classes and objects

Fields, a constructor, private state and toString.

A class describes objects; new Account("Ada") makes one. private fields can only be changed by the class’s own methods, so deposit can refuse a bad amount. final means the field is set once. Money is kept in whole cents as a long, because a double cannot hold 0.10 exactly.

@Override on toString tells the compiler to check that it really replaces the method every object inherits from Object; that is the method println calls.
