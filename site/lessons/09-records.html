Records, sealed types and patterns

Modern Java: data classes in one line, closed hierarchies, and switch on shape.

A record (Java 16) is a class for plain data: the compiler writes the constructor, the accessors, equals, hashCode and toString, which is why two Square(2) are equal.

sealed (Java 17) fixes the list of subtypes, so the switch in area can cover every case with no default; add a fourth shape and it stops compiling. case Rect(double w, double h) is a record pattern (Java 21): it checks the type and unpacks the fields in one step.
