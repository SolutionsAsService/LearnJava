Collections and generics

List, Map and Set, and one method that works for any comparable type.

List keeps order, Map pairs keys with values (TreeMap keeps the keys sorted), and Set drops duplicates. The type in angle brackets, List<String>, is a generic parameter: the compiler then refuses to put anything but a String in.

largest is generic too. It works for any T that can be compared, so the same code finds the last word alphabetically and the biggest number.
