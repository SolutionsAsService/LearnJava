Virtual threads

Ten thousand tasks, each with its own thread, all waiting at once.

A thread runs code at the same time as other threads. Platform threads are expensive, so programs used to share a few among many tasks. Virtual threads (Java 21) are cheap enough to give every task its own: here 10,000 tasks each sleep 10 milliseconds, and they all wait at the same time. One after another, they would take 100 seconds.

AtomicInteger counts safely from many threads at once; a plain int would lose updates. Leaving the try block waits for every task, so the count is always 10,000.
