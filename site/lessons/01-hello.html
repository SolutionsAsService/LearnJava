Hello, World

A class, a main method, one line printed.

Java code lives in classes. A class named Hello goes in a file named Hello.java. The program starts at main: public (anyone may call it), static (no object is needed to call it), and void (it returns nothing). String[] args holds any words typed after the program’s name.

javac compiles the file into Hello.class, and java runs it on the Java Virtual Machine (the JVM). The home page is that very .class file, byte for byte; Inside the JVM walks through it.
