Control flow

if, a switch that returns a value, and a while loop.

The switch here is an expression (Java 14): each arrow -> gives a value, there is no fall-through, and the result goes straight into kind. The while loop follows the Collatz rule from 27; nobody can say in advance how many steps it takes, which is what while is for.
