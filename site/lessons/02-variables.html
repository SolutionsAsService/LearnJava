Variables and types

Eight primitive types, var, and what happens past the largest int.

Java has eight primitive types, which hold a value directly: byte, short, int, long, float, double, char and boolean. Unlike C, their sizes are the same on every machine: an int is always 4 bytes. Everything else, a String included, is an object, reached through a reference.

var (Java 10) lets the compiler infer a local variable’s type; the type is still fixed. The last line shows overflow: one more than the largest int wraps around to the most negative one, silently.
