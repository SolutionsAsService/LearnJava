Lambdas and streams

Filter, map, sort and join a list in one expression.

A lambda, l -> l.year() > 2000, is a function written in place. A method reference, Lang::name, names an existing method instead. A stream passes each element through the steps in order; nothing happens until collect asks for the result. Lambdas and streams arrived in Java 8; this program also declares a record, which is why it needs Java 16.
