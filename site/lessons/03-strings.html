Strings

== compares objects, equals compares text, and strings never change.

== asks whether two references point at the same object; equals asks whether the text is the same. Use equals for strings.

A String is immutable: toUpperCase returns a new string and leaves the old one alone. To build text piece by piece, use a StringBuilder. Text blocks (three double quotes, """, Java 15) keep line breaks.
