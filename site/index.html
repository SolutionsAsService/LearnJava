What Java is

Java is a general-purpose language. Its compiler, javac, turns your code into bytecode: instructions for the Java Virtual Machine (the JVM), not for one kind of processor. So the same .class file runs unchanged on any computer with a JVM of the right version. Java manages memory for you, checks every array index, and catches many mistakes before the program runs, when it is compiled.
