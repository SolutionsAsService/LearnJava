What Java is

Java is a general-purpose language. Its compiler, javac, turns your code into bytecode: instructions for the Java Virtual Machine (the JVM), not for one kind of processor. So the same .class file runs unchanged on any computer with a JVM of the right version. Java manages memory for you, checks every array index, and catches many mistakes before the program runs, when it is compiled.

On the menu, “Java 21+” is the oldest version a lesson compiles under. For Java 8 and later the build proves it with javac --release; the older minimums (1.0, 5.0) come from the language’s history, because JDK 21 cannot compile for them.

See the bytes

Every Java program becomes a class file that starts with CA FE BA BE. Inside the JVM shows the whole of Hello.class, all 417 bytes, coloured by part.
