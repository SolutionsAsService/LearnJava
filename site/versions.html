Versions

Java has kept almost every old program running while it changed. Since 2018 a new version arrives every six months. Some are long-term-support (LTS) releases that companies stay on for years: 11 in 2018, 17 in 2021, and since then one every two years.

  • 19961.0Sun Microsystems releases Java: “write once, run anywhere” on the JVM. Lessons that need it: 01, 05
  • 19981.2The Collections framework: List, Map, Set.
  • 20045.0Generics, enums, annotations and the enhanced for loop. Lessons that need it: 06, 07
  • 20066Sun begins releasing Java as open source: OpenJDK.
  • 2010—Oracle acquires Sun, and with it Java.
  • 20117try-with-resources, the diamond <>, strings in switch.
  • 20148Lambdas, streams and the java.time dates. LTS
  • 20179Modules, and JShell for trying code line by line. Lessons that need it: 08, 10
  • 201810var, and a new release every six months, in March and September. Lessons that need it: 02
  • 201811Run a source file directly: java Hello.java. LTS Lessons that need it: 11
  • 202014Switch expressions, with -> and a value. Lessons that need it: 04
  • 202015Text blocks: strings in three double quotes that keep their line breaks. Lessons that need it: 03
  • 202116Records: a one-line class for plain data. Lessons that need it: 12
  • 202117Sealed classes. LTS
  • 202321Virtual threads, record patterns and pattern matching for switch. LTS Lessons that need it: 09, 13
  • 202525The current long-term-support release. LTS

This site is built with javac 21.0.12.1. The lesson numbers beside a version are the lessons that cannot compile under anything older. For Java 8 and later the build proves each one with javac --release.

Every program on this site was compiled with javac -Xlint:all on 2026-11-11 and run; the output shown is what it printed. How · Source · MIT licence.
